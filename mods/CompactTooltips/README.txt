Compact Tooltips
================

The tooltip shown when you hover an item takes far less space: tighter
spacing and text, a smaller value section, and each key hint on one short line
without the explanation under it. Nothing is hidden that tells you what the
item is or does.

Game files only; no loader code. Goes in
No Man's Sky\GAMEDATA\MODS\CompactTooltips. The shared parts it changes are
private copies (UI\BIGGERITEMGRIDS\TOOLTIP), so other screens keep the vanilla
look. CompactTooltips.lua names the files so the loader can merge them with
another AMUMSS script. Park it in the manager, or delete the folder, to remove it.

In this repository the UI files live in presets\CompactTooltips\default and
are added to the zip by release.py.
